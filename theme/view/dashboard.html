接口说明

路由由服务提供者在 boot 阶段注册，宿主项目无需复制路由文件。

GET{$api_base}/provinces

返回省/市树形数组，城市节点的 code 可直接作为天气接口的 stationid。

GET{$api_base}/weather?stationid=YVItN

原样返回中国天气网 JSON；stationid 不在白名单时回退默认城市，并返回 X-Weather-Fallback: 1。

静态资源由 {$asset}/<path> 路由直接输出，无需发布到 public。
